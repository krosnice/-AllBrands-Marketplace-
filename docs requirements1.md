# 🛡️ Управління ризиками та невизначеністю (Risk Management)

У цьому документі зафіксовані ключові технічні та бізнес-ризики проєкту "AllBrands Marketplace" на етапі MVP, а також стратегії їхнього пом'якшення (Mitigation Plans).

---

### 🚨 R-01: Розсинхронізація складів та залишків брендів
* **Опис ризику:** Оскільки маркетплейс агрегує сторонні сайти (Zara, Nike тощо), користувач може замовити річ, якої вже фактично немає на складі бренду-партнера. Це призведе до скасування замовлень та негативу.
* **Стратегія зменшення ризику:** На етапі MVP інтегрується чітке попередження в інтерфейсі кошика та на екрані успішного оформлення: *"Наявність товару та точний розмір підтверджуються менеджером під час контрольного дзвінка"*. Подальше оновлення ручної бази залишків виконується адміністратором за фіксованим розкладом.

---

### 🚨 R-02: Технічна складність інтеграції сторонніх API
* **Опис ризику:** Кожен світовий бренд має унікальну структуру даних, власні закриті API або захист від автоматичного збору інформації (scraping), що критично уповільнює розробку каталогу.
* **Стратегія зменшення ризику:** Повна автоматизація скасовується для першої ітерації. Для перевірки життєздатності інтерфейсу та вивчення реального попиту в базу даних вручну завантажується статичний топ-50 найпопулярніших товарів 3-х обраних брендів.

---

### 🚨 R-03: Низька довіра покупців до нової мультибрендової платформи
* **Опис ризику:** Нові користувачі можуть боятися купувати відомі дорогі бренди через страх отримати неоригінальний товар (підробку) або втратити гроші при передоплаті.
* **Стратегія зменшення ризику:** У межах MVP повністю виключається онлайн-еквайринг та передоплата картками. Розрахунок відбувається виключно у форматі "Накладений платіж" (оплата суворо після огляду та примірки речей у відділенні Нової Пошти). В інтерфейс додається помітний інформаційний інфоблок про гарантію повернення коштів та оригінальність.
