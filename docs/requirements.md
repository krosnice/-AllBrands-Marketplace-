##  9. Деталізація ключових NFR та Матриця трасування 

### Групування беклогу за епіками:
*   **EPIC-01: Каталог та Фільтрація** — `US-01`, `US-02`.
*   **EPIC-02: Управління Кошиком** — `US-03`, `US-04`.
*   **EPIC-03: Профіль та Оформлення** — `US-05`, `US-06`.

### Матриця трасування (Перевірка узгодженості FR -> US):


| Функціональна вимога (FR ID) | Пов'язана історія користувача (User Story ID) | Покриття критеріями приймання (AC) |
| :--- | :--- | :--- |
| **FR-01** | US-05 | AC-05.1, AC-05.2 |
| **FR-02** | US-01 | AC-01.1, AC-01.2 |
| **FR-03** | US-02 | AC-02.1, AC-02.2 |

| **FR-06** | US-06 | AC-06.1, AC-06.2 |

### Деталізація 3-х найважливіших NFR:
1. **NFR-01 (Продуктивність фільтрації):** Сервер має відповідати (TTFB) за \(\le\) 1.5 сек. Перевіряється в Chrome DevTools під навантаженням у 50 користувачів. Межа — 95% запитів мають вкластися в норму.
2. **NFR-02 (Мобільна адаптивність кошика):** Відсутність горизонтального скролу на екранах від 320px. Тест через Google Lighthouse. Межа — оцінка не менше 90 балів.
3. **NFR-03 (Надійність збереження даних):** Кошик зберігається 24 години. Тест шляхом закриття вкладки браузера та повторного входу. Межа — автоматичне відновлення товарів.
