# 📈 9. Деталізація ключових NFR та Матриця трасування (Високий рівень)

### Групування беклогу за епіками:
*   **EPIC-01: Каталог та Фільтрація** — включає в себе історії: `US-01`, `US-02`.
*   **EPIC-02: Управління Кошиком** — включає в себе історії: `US-03`, `US-04`.
*   **EPIC-03: Профіль та Оформлення** — включає в себе історії: `US-05`, `US-06`.

### Деталізація 3-х найважливіших NFR:
1. **NFR-01 (Продуктивність фільтрації):** Метрика — час відповіді сервера (TTFB) $\le$ 1.5 сек. Спосіб перевірки — автоматичний тест через Chrome DevTools (Network tab) під навантаженням у 50 одночасних користувачів. Межа приймання — якщо хоча б 95% запитів проходять швидше ніж за 1.5 сек, фіча вважається успішною.
2. **NFR-02 (Мобільна адаптивність кошика):** Метрика — абсолютна відсутність горизонтального скролу на екранах від 320px. Спосіб перевірки — тест за допомогою Google Lighthouse. Межа приймання — Score з UX/Accessibility не менше 90 балів.
3. **NFR-03 (Надійність збереження даних):** Метрика — час життя даних без авторизації становить 24 години. Спосіб перевірки — імітація збою: закриття вкладки, очищення активної сесії браузера та повторне відкриття сторінки маркетплейсу. Межа приймання — дані кошика відновлюються автоматично в повному обсязі.
